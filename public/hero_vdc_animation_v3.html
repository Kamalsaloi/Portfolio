{% comment %} VDC hero animation. This is the hero visual, included directly by landing_page.html. Variants v1 and v2 were deleted once this was chosen; they are recoverable from git history if the earlier framings are ever needed. PORTRAIT, 5/7. The composition is a single vertical column, so a 16/10 stage would letterbox it into a strip. Place it beside the hero copy rather than behind it, or change the aspect deliberately. Everything sits on x == y, so (x - y) is constant and the flow reads top to bottom on screen: proposal engine, glass box, verification plate, delivered pad, joined by dashed connectors. The container is a TRANSPARENT BOX, not an open tray. Back faces render first, then the contents, then the front faces at 0.10-0.13 opacity with the cube edges on top. That layering is what makes it read as glass. Sequence: the project lands on the engine as ONE undivided block (from v2 -- the split only reads if you first see the whole; mono and slices are flush at gap 0, so the swap is invisible), the engine separates it into three modules, and the modules DESCEND through the open top into the tray. They then stay put: each is a light shell over an accent fill, and the team fills them with blue to 100%. Earlier versions faded the modules out on arrival and grew a separate block from zero, so the tasks and the work looked unrelated. No machine is drawn where the split happens: a pedestal with a grey cube and a dot read as a mystery box, and it is unnecessary, because the split occurring ABOVE the container already says the team did not do it. Pulses run station -> tray while the fill climbs, so the team CAUSES the progress; agents pulse fast and continuously, humans slower. Build is 5.2s of the 13.6s loop. One block then travels down the column: box -> verification plate -> delivered pad. It is stamped ON the plate (the badge hovers above it) rather than turning green inside the box, and the modules empty behind it. Isometric has no z-buffer, so props inside the box are painted back to front by x+y depth. Palette is light throughout: workers neutral, agents blue- tinted, modules light until worked. Blue marks completed work and is the only saturated mass, per DESIGN-MARKETING.md's one-accent rule; green appears only after verification. Autoplays, pauses off-screen via IntersectionObserver, and holds the delivered frame under prefers-reduced-motion. {% endcomment %}
